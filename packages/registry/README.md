# @ruskel/registry

shadcn custom registry manifest.

```bash
npx shadcn@latest add https://ruskel.dev/r/ruskel-tokens.json
```

> **Validate before publishing.** The shadcn registry schema has moved more
> than once. Run `npx shadcn@latest registry:build` against this manifest and
> check the output against the current docs at ui.shadcn.com/docs/registry
> before pointing anything at it.
